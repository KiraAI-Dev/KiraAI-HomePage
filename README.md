# KiraAI 官网

[KiraAI](https://github.com/xxynet/KiraAI) 的官方网站，基于 Vite + Vue 3 构建。

## 开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

构建产物输出到 `dist/`，可部署到任意静态托管服务（GitHub Pages、Vercel、Cloudflare Pages 等）。
